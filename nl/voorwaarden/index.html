Gebruiksvoorwaarden

Instant Cities is een gratis spel, nog in ontwikkeling. Deze paar voorwaarden gelden als je het speelt of deze site gebruikt.

Kies een stad De code op GitHub

Gratis te spelen

Je kunt elke stad gratis spelen, zo vaak je wilt, zonder account. Je mag links naar de site, naar een stad of naar een bezienswaardigheid delen waar je maar wilt.

Zoals het is

Instant Cities is een zijproject en nog in ontwikkeling, dus hier en daar kan iets haperen. De site en het spel komen zoals ze zijn, zonder enige belofte dat ze op je toestel werken, online blijven of hetzelfde blijven. Niemand achter het project kan aansprakelijk gesteld worden voor schade door het gebruik ervan, voor zover de wet dat toelaat.

Geen kaart om op te vertrouwen

De steden zijn gebouwd uit OpenStreetMap en lijken op de echte plekken, maar ze zijn een spel, geen kaart. Straten, bruggen, gebouwen en bezienswaardigheden kunnen op de verkeerde plek liggen, er anders uitzien of ontbreken. Gebruik het spel niet om je weg te vinden, een route te plannen of in te schatten of een plek veilig is, en let op het echte verkeer als je echt gaat fietsen.

Kaartgegevens, foto’s en code

  • Kaartgegevens © OpenStreetMap-bijdragers, onder de Open Database Licence.
  • Foto’s van Mapillary en Wikimedia Commons houden hun eigen licenties, vermeld op de pagina waar ze staan.
  • De code is openbaar op GitHub, voor iedereen om te lezen en verbeteringen voor te stellen.

Wijzigingen

Deze voorwaarden kunnen veranderen naarmate het project groeit. De versie op deze pagina is die die geldt; bij twijfel geldt de Engelse versie. Vragen kunnen in een issue op GitHub.
