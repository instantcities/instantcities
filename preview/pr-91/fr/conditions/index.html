Conditions d’utilisation

Instant Cities est un jeu gratuit, encore en développement. Ces quelques conditions s’appliquent quand vous y jouez ou utilisez ce site.

Choisissez une ville Le code sur GitHub

Gratuit

Vous pouvez jouer gratuitement à chaque ville, aussi souvent que vous voulez, sans compte. Vous pouvez partager où vous voulez des liens vers le site, vers une ville ou vers un monument.

Tel quel

Instant Cities est un projet personnel, encore en développement : attendez-vous à quelques imperfections. Le site et le jeu sont fournis tels quels, sans aucune promesse qu’ils fonctionnent sur votre appareil, restent en ligne ou restent les mêmes. Personne derrière le projet ne peut être tenu responsable d’un dommage lié à leur utilisation, dans la mesure permise par la loi.

Pas une carte sur laquelle compter

Les villes sont construites à partir d’OpenStreetMap et ressemblent aux vrais lieux, mais c’est un jeu, pas une carte. Des rues, des ponts, des bâtiments et des monuments peuvent être mal placés, avoir un autre aspect ou manquer. N’utilisez pas le jeu pour trouver votre chemin, préparer un itinéraire ou juger si un endroit est sûr, et faites attention à la vraie circulation quand vous roulez à vélo pour de vrai.

Données cartographiques, photos et code

  • Données cartographiques © les contributeurs d’OpenStreetMap, sous la licence Open Database License.
  • Les photos de Mapillary et de Wikimedia Commons gardent leurs propres licences, créditées sur la page qui les montre.
  • Le code est public sur GitHub : chacun peut le lire et proposer des corrections.

Changements

Ces conditions peuvent changer à mesure que le projet grandit. La version de cette page est celle qui s’applique ; en cas de doute, la version anglaise fait foi. Les questions vont dans une issue sur GitHub.
