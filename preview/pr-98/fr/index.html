À propos du projet

Instant Cities est un projet open source avec un seul but : faire vivre une ville sur votre écran le plus simplement possible. Vous ouvrez un lien et vous voilà dans ses rues, sans rien installer, sans compte et sans ordinateur puissant.

Chaque ville est construite à partir d’OpenStreetMap et dessinée avec three.js dans le navigateur, et l’IA écrit la plus grande partie du code. Le code est sur GitHub : chacun peut le lire, l’utiliser et l’améliorer.
